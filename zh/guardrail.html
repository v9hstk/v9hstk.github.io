Guardrail：从第一性原理构建系统性交易基础设施

Single-family office · 多智能体架构 · 风险工程 · AI 行为分析 · 基础设施 2025–至今

执行摘要

Guardrail 是一家 single-family office，在数字资产、硬商品、房地产与前沿技术上运行自主资本配置系统。仅本金 — 无外部投资者、无 LP、无客户、无赎回闸门。在本作品集站点上，它也可读作 Hashstack 与 Parashar 旁的金融副业项目 — 不是冷触达主线故事。

我正在构建把这一姿态落地的交易基础设施 — 经 Redis 事件总线由编排器协调的 9 个专业子智能体执行系统、7 项程序化风险平面、AI 行为分析引擎，以及管理 43 任务部署 DAG 的构建编排器。guardrail.fund 公开定位：from signal to settlement — no human in the loop。

实盘栈的交易场所重点包括衍生品（Hyperliquid）与预测市场（Polymarket），处于更广的 SFO 使命之内。基础设施已上线。资本 100% 为本金 — 无第三方 LP 资本。

贯穿每个决策的两条原则：风险是闸门，不是仪表盘；以及人是最弱环节 — 每个随意干预点都是需要工程化移除的失败模式。

当前状态

1. 使命（公开定位）

据 guardrail.fund，配置覆盖四个垂直：数字资产、贵金属、房地产与技术（健康科技、保险、国防、航空航天、生物科技、量子）。运营论点包括硬货币稀缺（BTC + XAU）、可编程结算、实物真实收益地产，以及集中深科技押注。

本案例研究不是对外募资材料。它记录本金配置背后的系统性交易基础设施 — 风险、日志与行为监督如何在软件中强制执行。

2. 问题：多数交易者为何亏损

零售与小型运营商失败的三个原因与策略无关：

无系统化日志。 决策粒度不足，无法识别何有效。不知道按 setup、时间框架与市场状态划分胜率的交易者，是在猜测自己的优势。

无实时风险强制。 风险规则写在纸上，不在代码里。只有手动检查才触发的回撤上限不是上限 — 是建议。

情绪覆盖。 纪律在压力下系统性、可预测、可度量地退化。最难跳过的交易是亏损后的报复交易。

终端通过从执行环移除随意人工覆盖、用程序约束替代主观判断来同时解决三点。系统不建议纪律 — 它强制纪律。

3. 多智能体架构

系统在 Redis pub/sub 事件总线上由编排器协调 9 个专业子智能体。每个智能体拥有一个领域，发布类型化事件并消费其他智能体事件。无全局状态 — 协调经总线完成。

为何用智能体而非单体

每个智能体可独立失败。Exchange 宕机不会关闭 Risk。Journal 离线不停止仓位监控。Attention 失败降低洞察质量但不阻断执行。当级联失败意味着资本损失时，故障隔离至关重要。

事件总线设计

事件有类型（POSITION_OPENED、RISK_CHECK_FAILED、ANOMALY_DETECTED、DECAY_ALERT），带时间戳与来源标签。编排器路由跨智能体响应 — 例如 POSITION_LIMIT_BREACH → Exchange 减仓；TILT_DETECTED → 会话暂停升级。

4. AI 层：Attention + Summary

多数交易系统把 AI 当信号生成器。Attention 智能体不生成交易想法 — 它监视操作者。

它对照操作者自己的 Journal 基线对实时行为打分：亏损后仓位漂移、入场频率尖峰、持仓时间压缩、状态错配、信念–结果背离、会话模式变化。偏差发出类型化总线事件。Haiku 做实时打分；仅在异常确认且请求上下文时，Sonnet 才生成叙述解释。

Summary 智能体将跨智能体状态综合为会话报告、绩效归因、行为摘要与组合风险快照 — 是集体状态的读取层，而非第二研究引擎。

5. 7 项检查风险平面

风险不是仪表盘 — 是闸门。每笔交易执行前经过七项检查。任一项失败即阻断。平面设计为无随意绕过；若有例外，需可审计路径 — 而非当下的覆盖按钮。

Kelly 输入来自操作者按 setup 类型的 Journal 历史。Portfolio 智能体的 Monte Carlo 在批准新仓前建模组合尾部风险 — 捕捉各自安全但共同暴露于同一宏观因子的五条腿。

6. 构建编排器：43 任务部署 DAG

开发与部署使用 43 任务 DAG：依赖解析、API 限流自动恢复、每节点检查点、按任务类型的多模型路由（Haiku / Sonnet / Opus），以及按智能体回滚，使失败部署不拖垮全系统。

7. 钱包衰减诊断

资金费、手续费、滑点与舍入造成逐笔看似噪声的慢出血。Wallet Decay 智能体每 15 分钟核对期望与实际余额，并将侵蚀归因于资金费、手续费、滑点或舍入 — 让不可见的资本衰减可见。

8. 自动日志：29 字段

系统从交易所数据自动填充 29 字段中的 22 个，留下 4 个手动交易前 与 3 个手动交易后 输入（22 + 4 + 3 = 29）。Attention 字段与 TradingView 图表链接是叠加层 — 不会计入使日志膨胀到 33 的加法。

从不展示绝对美元金额 — 仅百分比、ROE 与 R 倍数。对预测市场，校准分数跟踪陈述置信度与结果随时间的匹配。该分数在公开预测市场终端中很少被当作一等指标。

9. 四层分离

严格仅向下依赖：

  • Orchestrator — 智能体协调、事件路由、工作流
  • Integrity — 哈希链审计日志、死人开关、紧急开关
  • Observability — BetterStack、Retool、Summary 智能体
  • Security — 只读密钥、命名空间事件、按智能体权限

每个决策与风险检查落入仅追加的 SHA-256 哈希链日志。紧急开关（手动平仓）与死人开关（心跳缺失 → 安全模式）保持分离，使一种失败模式无法同时抹掉两层保护。

11. QA — 目标运营纪律

目标节奏（非声称每项实践已按月仪式化）：每次部署的单元+集成测试、发布前回归套件、混沌工程（目标每月）、渗透测试（目标每季），以及经 GitHub Actions 的按智能体回滚 CI/CD。

12. 关键要点

关于定位： Guardrail 是仅本金的 SFO — 非客户基金、非 LP 载体。案例展示使自主配置可强制执行的基础设施。

关于风险工程： 风险仪表盘报告损害。风险闸门阻止损害。随意覆盖把闸门变成意见箱。

关于 AI： Attention 监视交易者，而非市场。Alpha 损失常来自好策略在压力下执行糟糕。

关于领域广度： 交付过 DeFi 协议产品工作的同一人，也构建系统性交易基础设施 — 不同领域，同样的“风险即接口”直觉。
