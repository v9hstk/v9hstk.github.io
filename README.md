# v9hstk.github.io

Personal site / recruiter **verification hub** for [Vinay Kumar](https://v9hstk.github.io) — not a portfolio agency site.

**Live:** https://v9hstk.github.io

## What’s here

- **Case studies** — product work (e.g. Hashstack), plus other published cases on the site
- **Resumes** — crypto and fintech PDFs under `assets/`
- **Contact** — LinkedIn, GitHub, X, email, Telegram, Cal.com (on the site)
- **Locales** — English default, plus `ar` / `de` / `jp` / `kor` / `zh`

Static site on GitHub Pages (`main` from repo root). No build step. Light, restrained design.
